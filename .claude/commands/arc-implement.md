## Привязка к инфраструктуре

1. **Предусловия — проверить до первой правки:**
   - `.arc/phase` = `implement`. Иначе любая правка будет отклонена хуком, и это
     правильно: значит план ещё не согласован.
   - `reports/01-audit/approved-plan.md` существует и не содержит `[ЗАПОЛНИТЬ]`.
     Нет согласованного плана — внедрять нечего, ОСТАНОВИСЬ.
   - Целевой репозиторий на рабочей ветке из `input/02_constraints.md`, дерево
     чистое (`git status` пуст). Не на той ветке или есть незакоммиченное —
     ОСТАНОВИСЬ, это ограничение №3 промпта.
   - `.arc/verify.json` заполнен (нет меток `[ЗАПОЛНИТЬ]`, baseline настроен, если он требуется планом).
     Проверить: `python scripts/verify.py --list`.
2. **Запрет на правки** из `.arc/protected.txt` действует и здесь, механически.
   Уперся в запрет — не обходи, вынеси в раздел `[СОГЛАСОВАТЬ: ...]`.
3. **Шаг 3 промпта = одна команда:** `python scripts/verify.py` после каждого
   пункта плана. Exit code 0 — можно дальше; иначе чинишь в рамках пункта, а не
   идёшь вперёд. Grep на удалённые компоненты — это шаг `removed-components`
   в `.arc/verify.json`: перед прогоном впиши туда имена удалённых агентов и
   функций, иначе проверка пройдёт вхолостую и отчёт получится лживым.
4. **Коммиты.** Один пункт плана — один коммит, хеш идёт в итоговую таблицу.
   Сообщение — по формату из `CLAUDE.md`, раздел «Коммиты»: тело объясняет решение
   и чем оно подтверждено, а в конце два обязательных поля —
   `ТЗ: <файл> — пункт <N> «<название>»` и `Версия: целевая-система X.Y.Z (в работе)`.
   Проверить перед коммитом: `python scripts/check_commit_message.py --file <msg>`.
   Итоговый коммит обновляет версию целевого проекта и получает тег.
   Пуш не делать без отдельного разрешения.
5. **Чекпоинт.** После каждого пункта уровня blocker/major — короткий статус
   (что сделано, что показали проверки) и стоп. Не продолжай без обратной связи.
6. **Отчёт** — `reports/02-implement/implementation-report.md`, все 7 артефактов,
   включая diff-статистику с отдельно выделенным числом удалённых строк.
